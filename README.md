Charity Management System

A web-based Charity Management System that connects donors, volunteers, and charity organizations. The platform allows users to donate goods and participate in charity events, making it easier to contribute to social causes and manage charitable activities.

📌 Features

👤 User Registration & Login

Create and manage user accounts.
Secure authentication for registered users.

🎁 Goods Donation

Donate useful goods to people or organizations in need.
Submit donation details through the website.

🤝 Volunteer Management

Users can register as volunteers.
Browse available volunteering opportunities.

🏢 Charity Management

Manage charity organizations and their activities.
Track donations and volunteer participation.

📊 Database Management

Store user, donation, event, and volunteer information using MySQL.

🛠️ Technology Stack
Technology	Purpose
HTML5	Structure and content of web pages
CSS3	Styling and responsive user interface
JavaScript	Client-side interactivity and validation
PHP	Server-side application logic
MySQL	Database management

The main objective of the Charity Management System is to provide a simple and centralized platform where people can contribute to charitable causes by donating goods and volunteering for charity events. The system helps organizations manage donations, volunteers, and events efficiently.
